# MetroidvaniaRPG · v0.1

基于 Unity 的 2D 跑酷、战斗与肉鸽原型。玩家从 0m 出发，沿随机生成、向右下方延伸的平台前进，在巨大黑影的追逐中战斗、收集金币并购买本局强化。

## 运行

1. 使用 **Unity 2022.3.53f1c1** 打开项目根目录，等待依赖与资源导入完成。
2. 补齐下文说明的本地素材库。
3. 打开 `Assets/Scenes/RunnerScene.unity`，或选择 **Tools → Runner → Open runner scene**。
4. 点击 Play。`SampleScene` 保留为基础战斗测试场景。

仓库提交 `Assets` 中的玩法源码、场景、动画、预制体，以及 `Packages`、`ProjectSettings`。Unity 缓存、IDE 工程文件、构建产物和本地验证输出不入库。

## 操作

| 按键 | 功能 |
| --- | --- |
| A / D、左右方向键 | 移动 |
| Space | 跳跃；购买强化后支持二段跳 |
| 左 Shift | 冲刺 |
| 鼠标左键 | 挥剑、衔接连击、反弹法球；支持空中攻击 |
| 1 / 2 / 3 | 购买商店对应商品 |
| Enter | 离开商店 |
| E | 在区域终点右侧出口进入下一区域 |
| R | 重新开始一局 |

## v0.1 内容

- 随机平台、悬空缺口、上下错落与奖励支路，整体向右下方延伸；长距离运行会回收地图并重定位世界坐标。
- 跨平台跳跃和击杀叠加 FLOW，第一档速度增加 50%，最高五档；层数越高，持续时间越短。
- 巨大黑影持续追逐，落后过远时加速追赶。玩家坠落会回到最后落脚平台，速度与 FLOW 归零；生命耗尽或被黑影追上会结束本局。
- 史莱姆、骷髅、死灵法师和镰刃怪，以及从右上方入场的空中幽灵。挥剑可反弹法球，并将怪群击退至后续平台。
- 玩家受伤仍扣血，但不被击退或打断。怪物仅在受伤后显示血条，不显示名字。
- 击杀和玩家正在击飞出屏幕的怪物可获得金币；单纯被甩在身后的怪物不结算。击飞金币会自动飞向玩家。
- 每约 800m 一处休息区，提供八种本局强化。基础价格为 110～220 金币，后续等级加价 40，刷新一次为 50。
- 顶部进度槽覆盖前后各 500m，显示玩家、黑影、起点、休息区、历史最高和区域终点。
- 每第三个休息区进入固定镜头场地，包含大平台与四个高低空中平台。通过出口可在旧城与暮色森林之间切换，背景、平台样式和怪物组合随区域变化。

**Boss 目前只有场地与区域过渡流程，尚未制作 Boss 对战。** 当前版本仍为玩法原型，数值与关卡节奏需要持续试玩调整。

## 素材依赖

沿用项目原有规则，以下本地素材库不提交到 Git：

- `Assets/Graphics/`
- `Assets/Tile Palette/`

因此本仓库不是包含完整素材的独立发行包。重新克隆后，需要从原项目补齐这两个目录，连同原有 `.meta` 文件一起复制，以保留场景和预制体的资源 GUID。仓库内的部分已提取运行图集不能替代完整素材库。

补齐素材后，可按需使用以下工具重新提取资源；这些操作会更新对应生成资产：

- **Tools → Runner → Refresh authored demo modules**：战斗 demo 的完整背景和已搭好的地面块。
- **Tools → Runner → Extract enemy assets**：地面怪物图集、动画与预制体。
- **Tools → Runner → Extract sky ghost assets**：空中幽灵。
- **Tools → Runner → Build region assets**：城镇、森林与怪物组合配置。
